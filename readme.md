Quick Start (Local)
1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Create a `.env` file with your development keys (if testing the API proxy). Example:

```
GOOGLE_API_KEY=your_key_here

```

4. Run locally:

```bash
npm run dev
```

Open `index.html` in a browser (or visit the local server) to try the theatrical demo. Remember: the experience is purely fictional.
